Print a verdict: a measured value against what hv-metal assumes.

★ The verdict is the product, not the raw register. A hex dump of ICH_VTR_EL2 tells a reader nothing about whether the vGIC’s context layout survives the port; “DIFFERS (4 assumed, 6 measured)” tells them exactly which code has to change. Mismatch is not failure — it is the finding this probe exists to produce.
